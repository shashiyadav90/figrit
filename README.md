# Figrit – Launching soon (React + Vite + Tailwind)

    npm install
    npm run dev

- `src/pages/LaunchingSoon.jsx` – the whole page: data, countdown and UI (Tailwind classes).
  Change `launchDate` and the `content` object at the top of the component.
- `src/index.css` only contains the three Tailwind directives (required by Tailwind).
